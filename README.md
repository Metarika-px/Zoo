# Зоопарк

Учебное Web-приложение на PHP 8 + MySQL для курсовой работы: учет животных, сотрудников, билетов, экскурсий, ролей и отчетов.

## Стек

- PHP 8+
- MySQL
- PDO и prepared statements
- Sessions и cookies
- Bootstrap 5
- Chart.js
- Чистый PHP без Laravel, Symfony, ORM и Composer

## Установка

1. Скопируйте проект в папку веб-сервера, например `htdocs/zoo`.
2. Создайте базу данных и импортируйте файл `database/zoo.sql`.
3. Проверьте настройки подключения в `config/config.php`.
4. Откройте `http://localhost/zoo/index.php`.

## Тестовые учетные записи

- Клиент: `client` / `12345`
- Сотрудник: `keeper` / `12345`
- Администратор: `admin` / `admin`
- Директор: `director` / `director`

## Возможности

- Регистрация и авторизация.
- Роли: гость, клиент, сотрудник, администратор, директор.
- Публичные страницы животных, вольеров, экскурсий и покупки билетов.
- Клиентский кабинет с заказами, профилем и сообщениями.
- Панель сотрудника с закрепленными животными и экскурсиями.
- Админ-панель с управлением животными, пользователями, билетами, экскурсиями и справочниками.
- Загрузка изображений животных.
- Массовое удаление животных.
- Email через стандартную функцию `mail`.
- Графики Chart.js для статистики директора и администратора.
- SQL views, functions и stored procedures.

## Важно

Проект учебный. Пароли намеренно хранятся без хеширования по требованию задания. В реальном проекте нужно использовать `password_hash` и `password_verify`.
